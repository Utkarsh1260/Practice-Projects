# 🧣 Cotton Weave — Fashion Product UI Recreation

## 📌 Project Overview

A frontend UI recreation built with HTML5 and CSS3, inspired by a modern textile and fashion product page. It includes navigation, product details, color options, pricing, rating, shopping action, image cards, and feature highlights.

## 🎯 Project Objective

This project strengthens core frontend skills through Flexbox, spacing, positioning, background images, typography, pseudo-elements, hover effects, and transitions.

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling, layout, and presentation
* **Flexbox** — Navigation, product layout, cards, and footer
* **CSS Positioning** — Product badges and shopping action
* **CSS Transitions** — Hover and scaling interactions
* **Background Images** — Product and textile visuals
* **Remix Icon** — Navigation and feature icons

## 📊 Project Metrics

* 1 HTML document and 2 CSS stylesheets
* 1 navigation bar and main product section
* 5 navigation links and 2 header icons
* 3 color options and 4 image preview cards
* 1 price badge, 1 rating badge, and 1 add-to-bag button
* 6 footer feature blocks
* 60px main heading

## 🧩 Key CSS Concepts

* Flexbox with `flex`, `gap`, and alignment
* Relative and absolute positioning
* `background-image`, `cover`, and positioning
* Pseudo-elements with `::before`
* `transform: scale()` and transitions
* `writing-mode` for vertical text
* `min-height: 100vh` for layout sizing
